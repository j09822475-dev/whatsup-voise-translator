# Voise Translator

Android-приложение: вы надиктовываете сообщение по-русски, оно переводится на английский,
озвучивается голосом, который вы выбрали в системе, и уходит в выбранный чат WhatsApp
аудиофайлом — при включённой автоотправке без единого дополнительного нажатия.

---

## Чего приложение НЕ делает (и почему)

Исходная идея была другой: нажать «голосовое» в самом WhatsApp, говорить по-русски и чтобы
в микрофон WhatsApp попадала уже английская речь. **На устройстве без root это невозможно**, и
не по одной причине, а по трём независимым:

1. **В Android нет виртуального микрофона.** Ни один API не позволяет приложению подать свой
   аудиопоток на вход `AudioRecord`/`MediaRecorder` другого приложения. Маршрутизация захвата
   зашита в audio HAL. Аналога VB-Cable или PulseAudio loopback здесь нет.
2. **Микрофон занят.** С Android 10 доступ к записи фактически эксклюзивен: пока WhatsApp пишет
   голосовое, фоновое приложение получит тишину.
3. **Перевод не бывает синхронным.** Фразу нужно дослушать, распознать, перевести и
   синтезировать — это последовательная цепочка, минимум 1–3 секунды. Влить результат в уже
   идущую запись физически некуда.

Обойти это можно только на уровне системы: кастомная прошивка, Magisk-модуль виртуального
микрофона или LSPosed-хук на сам WhatsApp. Это не то, что делает обычный APK.

Поэтому здесь другой сценарий: **диктовка идёт в это приложение**, а в WhatsApp попадает
готовый результат. Плавающая кнопка поверх экрана делает разницу почти незаметной —
вы нажимаете её прямо поверх открытого чата.

Ещё одно честное ограничение: WhatsApp не даёт сторонним приложениям создавать *настоящие*
голосовые сообщения (те, что с волной и кружком аватара). Аудио уходит вложением — оно играет
прямо в чате встроенным плеером, но выглядит как файл, а не как voice note.

## Как это работает

```
речь (ru)  ──►  SpeechRecognizer  ──►  текст (ru)
                                          │
                                          ▼
                             ML Kit (офлайн) или Gemini API
                                          │
                                          ▼
                                     текст (en)
                                          │
                                          ▼
                     системный TextToSpeech → WAV → AAC/M4A
                                          │
                                          ▼
                    Intent.ACTION_SEND ──► WhatsApp ──► чат
                                          │
                                    (опционально)
                                          ▼
                        служба спец. возможностей жмёт «Отправить»
```

| Слой | Реализация | Файл |
|---|---|---|
| Распознавание | `android.speech.SpeechRecognizer`, поток событий | `speech/SpeechRecognizerController.kt` |
| Перевод (офлайн) | ML Kit on-device, модель ru→en качается один раз | `translate/MlKitTranslator.kt` |
| Перевод (онлайн) | Gemini REST API, свой ключ | `translate/GeminiTranslator.kt` |
| Синтез речи | Системный `TextToSpeech`, выбор голоса/скорости/тона | `tts/TtsEngine.kt` |
| Кодирование | `MediaCodec` + `MediaMuxer`, WAV → AAC в MP4 | `audio/AacEncoder.kt` |
| Отправка | `ACTION_SEND` + `FileProvider`, либо ссылка `wa.me` | `whatsapp/WhatsAppSender.kt` |
| Автонажатие | `AccessibilityService`, окно 20 секунд | `whatsapp/WhatsAppAutoSendService.kt` |
| Плавающая кнопка | Overlay поверх других приложений | `overlay/BubbleService.kt` |

Никаких платных сервисов в базовой конфигурации: распознавание, перевод и синтез — всё
системное или бесплатное на устройстве. Gemini подключается по желанию, если качество
офлайн-перевода на разговорных фразах покажется слабым.

## Сборка

Нужен Android SDK (API 35) и JDK 17+.

```bash
# в Android Studio: File → Open, выбрать корень репозитория
# или из терминала:
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

`assembleRelease` тоже собирается и подписывается debug-ключом — приложение рассчитано на
установку себе, а не на публикацию в Google Play (служба спец. возможностей, используемая для
автонажатия кнопки в чужом приложении, политикам Play не соответствует).

## Настройка на телефоне

1. **Микрофон** — разрешение запрашивается при первом запуске.
2. **Голос.** Настройки → «Голос». Если список пуст, откройте системные настройки синтеза речи
   и скачайте English (US) для Google Speech Services. Кнопка «Прослушать образец» проверяет
   выбор до отправки.
3. **Перевод.** По умолчанию офлайн. Нажмите «Скачать модель заранее», чтобы первая диктовка не
   ждала загрузку. Для Gemini вставьте свой ключ и укажите модель.
4. **Чаты.** Настройки → «Чаты» → имя + номер в международном формате. Имя должно совпадать с
   тем, как контакт подписан в WhatsApp — по нему служба спец. возможностей находит чат, если
   WhatsApp покажет список выбора.
5. **Автоотправка** (по желанию). Включите переключатель, затем «Открыть спец. возможности» и
   активируйте там Voise Translator. Служба работает только 20 секунд после того, как вы сами
   нажали отправку, и только на экранах WhatsApp — это задано в манифесте.
6. **Плавающая кнопка** (по желанию). Разрешите наложение поверх других приложений и нажмите
   «Показать».

## Обычный сценарий

Открыт чат в WhatsApp → тап по плавающей кнопке → говорите по-русски → тап по кнопке «стоп»
(или молчите пару секунд) → приложение переводит, озвучивает и передаёт файл в WhatsApp →
служба жмёт «Отправить».

Перед отправкой можно поправить и распознанный русский («Перевести заново»), и английский
перевод («Озвучить заново»).

## Что может сломаться

- **Автонажатие.** Опирается на id и подписи кнопок внутри WhatsApp (`send`, `send_btn`,
  `media_send`, contentDescription «Send»/«Отправить»). WhatsApp их периодически меняет. Если
  перестало работать — выключите автоотправку, отправка руками продолжит работать всегда.
- **Открытие нужного чата сразу.** Использует недокументированный extra `jid`. Если WhatsApp его
  перестанет понимать, откроется обычный список выбора чата — это одно лишнее нажатие, а не
  поломка.
- **Качество офлайн-перевода.** ML Kit заметно проще Gemini на разговорных фразах и идиомах.
  Переключатель движка в настройках как раз для этого.
